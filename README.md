# 💎 Free Fire Tools - Công Cụ Tính Toán & So Sánh Nạp Kim Cương

Một trang web siêu xịn xò dành cho các game thủ Free Fire (Lửa Chùa). Công cụ này giúp bạn tính toán chính xác số kim cương (KC) cần thiết cho các sự kiện, cũng như tư vấn chiến lược nạp tiền thông minh nhất để tiết kiệm tối đa "hầu bao".

## ✨ Tính Năng Nổi Bật

### 🎯 1. Tính Kim Cương Sự Kiện
- **Tính tự động:** Dựa vào giá gốc huy hiệu, số lượng cần mua, và giới hạn mua mỗi sự kiện để tính ra số sự kiện bạn cần tham gia.
- **Mô phỏng giảm giá:** Cho phép random tỷ lệ giảm giá (từ 50% đến 85%) hoặc tự chọn tỷ lệ cho từng sự kiện.
- **Trực quan:** Hiển thị số KC min/max và biểu đồ đường (sử dụng Chart.js) trực quan, đẹp mắt để thấy sự thay đổi số KC qua từng mốc sự kiện.
- **Tối ưu chi phí ra VNĐ:** Tự động quy đổi số KC cần thiết ra tiền Việt theo các chiến lược: nạp thường, thẻ tháng, thẻ tuần, và gói tối ưu nhất.

### 💰 2. So Sánh Các Gói Nạp
- Bảng so sánh trực quan giữa các lựa chọn phổ biến (Nạp 100 KC bonus, Thẻ Tuần, Thẻ Tháng).
- Cung cấp tỷ lệ sinh lời (%) và số KC thực nhận để tìm ra "Best Deal".
- Đề xuất gói nạp phù hợp theo từng phong cách chơi (lâu dài vs tức thời).

### 🎨 3. Giao Diện & Trải Nghiệm (UI/UX)
- Giao diện phong cách **Dark Mode / Cyberpunk** với các dải màu neon xanh dương và xanh lá đậm chất Free Fire.
- Hiệu ứng kim cương rơi siêu ảo diệu (Canvas Animation).
- **Responsive 100%**: Trải nghiệm mượt mà trên cả PC lẫn điện thoại.

## 🛠️ Công Nghệ Sử Dụng (Tech Stack)

Dự án được xây dựng siêu nhẹ và tối ưu hóa tốc độ cao nhất, không sử dụng Framework phức tạp:
- **Ngôn ngữ:** HTML5, CSS3, JavaScript (Vanilla JS).
- **Thư viện:** [Chart.js](https://www.chartjs.org/) (Vẽ biểu đồ sự kiện).
- **Thuật toán cốt lõi:** Sử dụng **Quy hoạch động (Dynamic Programming)** để tính toán tổ hợp nạp rẻ nhất, tiết kiệm nhất trong hàng ngàn khả năng nạp khác nhau.
- **Triển khai (Deployment):** Sẵn sàng để đẩy lên GitHub Pages, Vercel hoặc Netlify.

## 🚀 Cách Sử Dụng Ngay Trên Máy Của Bạn

Bởi vì đây là một dự án **Single Page Application (SPA)** hoàn toàn tĩnh, bạn không cần cài đặt Node.js hay thiết lập server lằng nhằng!

1. Clone (tải) thư mục này về máy.
2. Click đúp chuột vào file `index.html`.
3. Trang web sẽ tự động mở lên trong trình duyệt (Chrome, Safari, Edge,...) của bạn.
